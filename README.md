# Portofolio lovely 

Portofolio pribadi yang dibangun dengan HTML, CSS, dan JavaScript murni. Desain elegan dengan palet warna warm ink, cream, dan champagne gold — sesuai estetika Lilyzhao.

## Cara Deploy ke GitHub Pages

1. Repository ini sudah siap.
2. Pergi ke Settings → Pages
3. Pilih branch `main` dan folder `/ (root)`
4. Save
5. Situs akan tersedia di `https://lovelylengkong08-cpu.github.io/portfolio`

## Kustomisasi

- Edit teks di `index.html` sesuai bio, proyek, dan kontak Anda.
- Ubah warna di `style.css` jika ingin menyesuaikan dengan brand VELA atau lainnya.
- Tambahkan foto, link proyek, atau section baru sesuai kebutuhan.
